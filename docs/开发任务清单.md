### 标准启动顺序（大项目顺利运行前提）

```bash
uv sync --group dev
uv run playwright install chromium
uv run python scripts/verify_environment.py   # ① 环境自检（阶段〇-C 交付后）
uv run python scripts/start_platform.py       # ② 采集层（必须）
# 待阶段〇-B 完成后：
# uv run uvicorn app.main:app --reload       # ③ 平台 API
# cd web/frontend && npm ci && npm run dev   # ④ 展示层
```
