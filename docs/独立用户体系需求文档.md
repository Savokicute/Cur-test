# 独立用户体系 - 完整闭环需求文档

> **文档版本**: V1.0
> **创建日期**: 2026-06-08
> **项目**: TrendRadar 热点发现平台
> **状态**: 待开发

---

## 1. 需求概述

### 1.1 目标
构建 TrendRadar 独立用户体系，实现**注册 → 登录 → 个人中心 → 密码管理**完整闭环。

### 1.2 核心决策

| 决策项 | 选择 |
|--------|------|
| 用户数据来源 | **独立用户体系**（TrendRadar 自身管理） |
| 注册方式 | 用户名 + 密码（邮箱选填） |
| 注册审核 | 自动开通（默认角色：普通用户） |
| 密码规则 | **8位+，必须含大小写字母 + 数字 + 特殊字符** |
| 找回密码 | 管理员后台重置（用户需强制改密） |
| 登录并发 | **单点登录**（新登录踢掉旧会话） |
| 注册入口 | 登录弹窗内切换注册表单 |
| 个人中心入口 | Header 下拉菜单 + 侧边栏独立页面 |

## 2. 功能模块清单

### 2.1 注册功能

| 功能项 | 说明 |
|--------|------|
| 注册表单 | 用户名(必填, 3-20字符) + 密码(8位+) + 确认密码 + 邮箱(选填) |
| 用户名唯一性校验 | 输入时实时检查是否已存在 |
| 密码强度提示 | 实时显示密码强度（弱/中/强） |
| 邮箱格式校验 | 选填但填了必须合法 |
| 注册成功 | 自动登录并跳转首页 |

### 2.2 登录功能

| 功能项 | 说明 |
|--------|------|
| 本地密码验证 | 对比 bcrypt 哈希 |
| 单点登录 | 新登录成功后使旧 Token 失效 |
| 记住我 | 7 天免登录 |
| 强制改密标记 | `force_change_password=True` 时跳转改密页 |
| 登录失败次数限制 | 连续 5 次失败锁定 15 分钟 |

### 2.3 个人中心

| 功能项 | 说明 |
|--------|------|
| 基本信息 | 查看/修改 昵称、邮箱、头像 |
| 修改密码 | 旧密码 + 新密码(符合规则) + 确认密码 |
| 权限查看 | 当前角色 + 权限列表（只读） |
| 登录历史 | 最近 10 条登录记录（时间/IP/设备） |

### 2.4 管理员重置密码

| 功能项 | 说明 |
|--------|------|
| 重置接口 | PUT /api/users/{username}/reset-password |
| 设置临时密码 | 随机生成 16 位临时密码 |
| 强制改密标记 | 设置 `force_change_password=True` |
| 通知用户 | 返回临时密码供管理员告知用户 |

## 3. 数据库设计

### 3.1 users 表（新增 - 替代 we-mp-rss 依赖）

```sql
CREATE TABLE IF NOT EXISTS users (
    username        VARCHAR(50)  PRIMARY KEY,       -- 用户名（唯一）
    password_hash   TEXT         NOT NULL,           -- bcrypt 哈希
    nickname        VARCHAR(100),                    -- 昵称
    email           VARCHAR(255) UNIQUE,             -- 邮箱（可选）
    avatar          VARCHAR(500),                   -- 头像 URL
    role            VARCHAR(32)  NOT NULL DEFAULT 'user',  -- 角色: super_admin / user
    is_active       BOOLEAN      NOT NULL DEFAULT TRUE,
    force_change_password BOOLEAN NOT NULL DEFAULT FALSE,  -- 强制改密标记
    login_count     INTEGER      DEFAULT 0,
    last_login_at   DATETIME,
    last_login_ip   VARCHAR(45),
    failed_attempts INTEGER      DEFAULT 0,          -- 连续失败次数
    locked_until    DATETIME,                       -- 锁定截止时间
    remark          TEXT,                           -- 管理员备注
    created_at      DATETIME     DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 login_logs 表（新增）

```sql
CREATE TABLE IF NOT EXISTS login_logs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    username        VARCHAR(50)  NOT NULL,
    ip_address      VARCHAR(45),
    user_agent      TEXT,
    success         BOOLEAN      NOT NULL,           -- 是否成功
    failure_reason  VARCHAR(100),                    -- 失败原因（如：密码错误/账号锁定）
    created_at      DATETIME     DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_login_logs_username ON login_logs(username);
CREATE INDEX idx_login_logs_created ON login_logs(created_at);
```

## 4. API 设计

### 4.1 认证 API

| 方法 | 路径 | 描述 | 认证 |
|------|------|------|------|
| POST | `/api/auth/register` | 注册 | 无 |
| POST | `/api/auth/login` | 本地登录 | 无 |
| POST | `/api/auth/logout` | 退出登录 | 需要 |
| GET | `/api/auth/me` | 当前用户信息 | 需要 |
| GET | `/api/auth/permissions` | 当前权限列表 | 需要 |

### 4.2 个人中心 API

| 方法 | 路径 | 描述 | 权限 |
|------|------|------|------|
| GET | `/api/profile` | 我的个人信息 | 自己 |
| PUT | `/api/profile` | 修改个人信息 | 自己 |
| POST | `/api/profile/change-password` | 修改密码 | 自己 |
| GET | `/api/profile/login-history` | 登录历史 | 自己 |

### 4.3 管理员扩展

| 方法 | 路径 | 描述 | 权限 |
|------|------|------|------|
| PUT | `/api/users/{username}/reset-password` | 重置密码 | user:edit |
