## 如何启动和测试

### 1. 安装依赖

```bash
cd web/frontend
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问 `http://localhost:5173`

### 3. 功能测试清单

| 功能 | 位置 | 测试内容 | 状态 |
|------|------|----------|------|
| 侧边栏导航 | 左侧菜单 | 点击菜单项，页面跳转 | ⏳ |
| 侧边栏折叠 | 左侧菜单 | 点击折叠按钮 | ⏳ |
| 标签页切换 | 内容总览 | 切换不同标签页 | ⏳ |
| 搜索功能 | 内容总览/素材中心 | 输入关键词搜索 | ⏳ |
| 收藏功能 | 内容总览 | 点击收藏按钮 | ⏳ |
| 查看详情 | 内容总览 | 点击内容项或查看详情 | ⏳ |
| 编辑收藏 | 素材中心 | 点击编辑按钮 | ⏳ |
| 删除收藏 | 素材中心 | 点击删除按钮 | ⏳ |
| 刷新数据 | 顶部栏 | 点击刷新按钮 | ⏳ |
| 表单提交 | 所有页面 | 填写表单并提交 | ⏳ |
| 开关切换 | 多个页面 | 点击开关控件 | ⏳ |

### 4. 后端服务（可选）

如果需要完整功能，同时启动后端服务：

```bash
cd web/backend
python -m uvicorn main:app --reload --port 8000
```
